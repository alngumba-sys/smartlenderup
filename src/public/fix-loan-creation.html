🔧 Fix Loan Creation Error

PGRST204: Could not find 'amount' column
⚠️ What's happening?
This is a Supabase schema cache issue. The column exists in your database, but Supabase's internal cache doesn't know about it yet. This commonly happens after database migrations or schema changes.

1 Run SQL Fix

  1. Open your Supabase Dashboard
  2. Go to SQL Editor (left sidebar)
  3. Click "New Query"
  4. Open the file /FIX_LOAN_CREATION_SCHEMA.sql from your project
  5. Copy all the SQL and paste it into the SQL Editor
  6. Click "Run" to execute

2 Refresh Schema Cache

This is the most important step!

Method A: Dashboard (Easiest)

  1. In Supabase Dashboard, click "API" in left sidebar
  2. Scroll down to find "Refresh schema cache" button
  3. Click the button
  4. Wait 30-60 seconds before testing

Method B: Restart Project (Most Reliable)

  1. Go to Settings → General
  2. Click "Pause project" and wait
  3. Click "Resume project"
  4. Wait 1-2 minutes for project to fully restart

3 Clear Browser Cache

  1. Press F12 to open DevTools
  2. Go to Application tab (Chrome) or Storage tab (Firefox)
  3. Clear Local Storage and Session Storage
  4. Do a hard refresh:
    • Windows/Linux: Ctrl + Shift + R
    • Mac: Cmd + Shift + R

4 Test Loan Creation

  1. Go back to your SmartLenderUp dashboard
  2. Navigate to Loans tab
  3. Click "New Loan"
  4. Fill in all required fields
  5. Click "Create Loan"
✅ Success!
If the loan is created without errors, you're all set! The loan will appear in your loans list with an auto-generated loan number (e.g., "BVF-LN00001").

🆘 Still Not Working?

  • Wait longer: Schema cache refresh can take up to 2 minutes
  • Check browser console: Press F12 and look for error messages
  • Verify SQL ran: Go to SQL Editor and run:
    SELECT column_name FROM information_schema.columns WHERE table_name = 'loans';
  • Check Supabase logs: Dashboard → Logs → look for errors
  • Try incognito mode: Open your app in a private/incognito window
