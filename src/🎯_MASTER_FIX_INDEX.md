## 🎓 Understanding Your Setup

### What is Supabase?
- PostgreSQL database in the cloud
- Stores all your organization, client, loan data
- Provides REST API for your app to access data

### What is RLS?
- Row Level Security
- Controls who can access what data
- We disable it for testing (easier)
- Should enable it for production (more secure)

### What are the SQL scripts?
- **SETUP:** Creates tables (organizations, clients, loans, etc.)
- **DISABLE_RLS:** Turns off permissions (for testing)
- **CLEANUP:** Deletes everything (fresh start)
- **DIAGNOSTIC:** Checks what's wrong

### What is the demo account?
- Username: `12345`
- Password: `Test@1234`
- Pre-configured admin account
- Works without database setup
- Perfect for testing
