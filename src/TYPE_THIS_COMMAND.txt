IF YOU SEE THE ERROR AFTER RUNNING npm run dev:

You're looking at an OLD browser tab from BEFORE you ran the command.

FIX:
  → Close the browser tab
  → Open a NEW tab
  → Go to: http://localhost:5174
  → Error disappears!
