🔬 Why This Works (Technical Explanation)

Browser cache is PORT-SPECIFIC.

When you visit localhost:5173, your browser caches the JavaScript files FOR THAT PORT.

Those cached files (from before the fix) try to import @supabase, which loads WebAssembly.

When you visit localhost:5174, your browser has NO CACHED FILES for that port.

So it downloads FRESH JavaScript files from the dev server. Those fresh files have NO @supabase and NO WebAssembly.

Result: NO ERROR!
